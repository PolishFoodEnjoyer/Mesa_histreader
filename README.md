# Mesa_histreader
A simple python program for reading the history.data file output by the MESA program.

# Limitations

Currently (as of 16.11.2026) this program only works for the default arrangement of the history.data file output by MESA.

# Versions

Mesa_histreaderV1 works in a terminal environment and only requires numpy. Mesa_histreaderV2 works in its own window and also requires tkinter.
